# ForgeWorld Ω — Sovereign Substrate (FW-SCS-001)

An offline-first, two-device evidence substrate. The phone (pocket node) and the PC (forge
node) each keep a complete, independently usable, append-only and signed memory. They exchange
verified evidence through an authenticated, encrypted, interruption-tolerant protocol: live
over the LAN, or as sealed files when they are never online together.

**Status, honestly stated:** the acceptance scenario passes as a reproducible test with two
independent node stores on one Linux host. It has **not yet** been run on a real Android phone
or Windows PC, or against real Ollama. See [CAPABILITY_STATUS.md](CAPABILITY_STATUS.md) and
[LIMITATIONS.md](LIMITATIONS.md).

## Module map

```
omega/
  canonical.py     deterministic JSON (reuses cognition.cxp) + domain-separated sha256
  policy.py        closed vocabularies; who may write which event (human-only governance)
  identity.py      Ed25519 / X25519 device keys, pairing offers, 6-digit SAS
  events.py        fw.omega.event/1: signed header + hashed payload, strict validation
  store.py         SQLite node: append-only triggers, artifacts, FTS5, import, purge, retention, integrity
  receipts.py      deterministic, signed, hash-chained receipts
  reconcile.py     causal heads per state key; explicit conflicts; human resolution
  relationship.py  contacts, messages, facts, commitments; draft checks; offline drafting
  commercial.py    claimed vs verified payment and the other Stage G distinctions
  tasks.py         durable queue; device-local execution; local human authorization
  sync.py          handshake, encrypted session, resume, offline sealed bundles, TCP
  discovery.py     signed UDP beacons
  forge.py         Ollama client, hardware profile, benchmarks, evidence-based model routing, repo analysis
  agents.py        advisory specialist panel
  evolution.py     experiments, promotion gate, rollback points (human decides)
  diagnostics.py   payload-free diagnostic / mission-control report
  cli.py           python -m omega …
  demo_e2e.py      the final acceptance scenario
```
