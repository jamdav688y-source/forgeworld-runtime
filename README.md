# FORGEWORLD PHONE NODE

This phone is the field command terminal.

Primary roles:
- Capture
- Observe
- Queue
- Monitor
- Command
- Review

This phone is not the heavy build engine.
The laptop builds.
GitHub stores.
ChatGPT governs.
Codex assists.

## Continuity Substrate

Every capture on this phone and every build on the laptop now feeds one
shared memory system. See `substrate/README.md` for the mission format,
registries, and phone/laptop scripts that make captured ideas into reusable
capability instead of scattered notes.
